Technical Deep Dive

📊

The Dataset

Recobook utilizes a curated library of over 6,000 book records. Each entry includes metadata and detailed summaries, which are vectorized and mapped against user profiles to provide accuracy recommendations.

  • Comprehensive Book Summaries
  • Multi-Genre Classification
🧠

The Intelligence

We use the all-MiniLM-L6-v2 sentence-transformer model. This allows us to convert text into 384-dimensional vectors for precise semantic similarity searching.

  • Semantic Vector Embeddings
  • NLP-based Profile Matching
  • Cosine Similarity Optimization
